# Faceplate STL sections from the marked sketch

Seven full-area STL sections follow the approximate red split marks in the user's screenshot: [top center](top-center.stl), [upper control side](upper-control.stl), [lower control and speaker](lower-control-speaker.stl), [bottom center](bottom-center.stl), [lower left](lower-left.stl), [left center](left-center.stl), and [upper left](upper-left.stl). The split coordinates are rounded to clean millimeter values and listed in [validation.json](validation.json); the strokes were not treated as exact measurements.

The complete faceplate remains 816.2 × 434.75 mm with the existing screen and speaker openings. Each STL is **1.25 mm thick**, one watertight body, fits individually within 420 × 420 mm, and has through-thickness dovetail joints. Physical joint fit and a shared build-plate arrangement have not been verified.

The [original one-sheet PDF](../faceplate-a1-and-eight/faceplate-cutouts-a1-one-sheet.pdf) remains a single unsplit template with the outer edge, both openings, scale checks, and knob-center references.
