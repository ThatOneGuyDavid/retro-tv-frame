# Example dimensions and coordinate system

All dimensions are millimeters unless labeled otherwise. These measurements describe a **generic square-edged reference envelope**, not a named display model. The glass and housing are modeled as one solid unit; no internal display construction is inferred.

## Display

| Measurement | Value |
| --- | ---: |
| Viewing width × height | 596.9 × 336.55 (23.5 × 13.25 inches) |
| Factory border top / bottom | 34 / 48 |
| Factory border left / right | 33 / 33 |
| Factory front above glass | 7 |
| Complete housing width × height × depth | 662.9 × 418.55 × 44 |

Origin is the **center of the viewing surface**, with glass front **Z=0**, X right, Y up, Z toward the viewer. Factory frame front is Z=7 and housing back Z=-37. Because the lower border is taller, the housing's outer center is Y=-7. Housing bounds are X=±331.45, Y=-216.275..202.275, Z=-37..7.
